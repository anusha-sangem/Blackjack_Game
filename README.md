# 🃏 Blackjack Game

A simple and interactive **Blackjack game built using JavaScript**. Start the game, draw cards, and try to reach a total of 21 without exceeding it!

## 🎮 About the Game

This project is a beginner-friendly card game that demonstrates JavaScript fundamentals, including variables, functions, conditional statements, and DOM manipulation.

## ✨ Features

- **Start Game:** Click the Start Game button to begin playing with cards.
- **Track Your Sum:** Shows the total value of your cards.
- **Draw a New Card:** Click the New Card button to draw another card if your total is less than 21.
- **Blackjack Win:** Reach exactly 21 to win the game.
- **Bust:** If your total exceeds 21, you are out of the game.

## 🕹️ How to Play

1. Click **Start Game** to begin.
2. If your sum is less than 21, click **New Card** to draw another card.
3. Reach exactly 21 to get a Blackjack and win.
4. If your sum exceeds 21, you lose the game.

### Game Rules

| Less than 21 | Draw another card |
| Exactly 21 | Blackjack! You win 🎉 |
| Greater than 21 | Bust! Game over ❌ |

- **JavaScript** – Implements the game logic, card values, and win/loss conditions.
